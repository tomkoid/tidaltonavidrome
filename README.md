# Migrate playlists from TIDAL to Navidrome

Just a quick script I quickly vibe-coded to migrate playlists from TIDAL to Navidrome. It uses the TIDAL API to fetch playlists and then creates them in Navidrome using its API.

Change the `TIDAL_USER_ID`, `TIDAL_SESSION_ID`, and `NAVIDROME_URL` variables to your own values before running the script.
